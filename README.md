# Auditoría de tarifas

Aplicación web estática para revisar el próximo cobro de la nómina de abonados.

## Privacidad

- El Excel o CSV se procesa completamente dentro del navegador.
- La nómina no se carga ni se envía a GitHub ni a otro servidor.
- Las revisiones y tarifas se conservan en el almacenamiento local del navegador utilizado.
- El JSON de tarifas descargable no incluye abonados, nombres ni filas de la nómina.
- Este repositorio público contiene únicamente los archivos estáticos necesarios para ejecutar la herramienta; no contiene nóminas ni datos de clientes.
